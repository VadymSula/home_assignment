## AI-Assisted Development Documentation

Maintain AI_PROMPTS.md as a chronological log of AI-assisted development.

After completing each meaningful implementation, refactoring, debugging, or architectural task, append a new entry using the following format:

### Prompt #XX — Task Title

**Date:** YYYY-MM-DD

**Context:**

Briefly describe the purpose of the task.

**Prompt:**

Include the original user prompt without modifications.

**Outcome:**

Summarize the actual implementation results.

**Changed Files:**

List the created, modified, or deleted files.

**Validation:**

Describe the performed validation and its actual results, including any errors or limitations.

**Human Review & Comments:**

---

### Documentation Rules

- Maintain sequential prompt numbering.
- Preserve previous entries.
- Do not modify or summarize the original user prompt.
- Do not document trivial or unrelated interactions.
- Do not fabricate implementation or validation results.
- Leave the Human Review & Comments section empty for manual input.
- Never modify previously written human comments.
